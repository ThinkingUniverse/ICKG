# 3.4 慢病/亚健康免疫风险追踪

> **使用场景 / 解决的问题**：慢病（如糖尿病、慢性肝病、自身免疫病稳定期）与亚健康人群，免疫状态会**长期、缓慢地漂移**，单次体检看不出来。本场景对这类人群做**长期、个人化的免疫风险追踪与预警**，在风险抬头时及时提示就医。
>
> **与 [2.1 预防](../02_clinical_applications/2.1_prevention.md) 的区别**：2.1 偏**临床队列建模**（在 EHR 队列上训练风险模型、做人群级早期识别）；本场景偏**个人长期管理**（面向 C 端个体的持续追踪与生活化预警），二者共用 ICKG 与风险机制，但产品形态与受众不同。

## 一、应用价值

- **慢病人群**：糖尿病/慢性肝病/肾病等常伴免疫功能改变与慢性炎症，长期追踪免疫指标有助于早期发现并发风险。
- **亚健康人群**：反复感染、易疲劳、慢性低度炎症等，缺乏明确诊断却有管理价值。
- **核心**：把"一次性体检"升级为"**带机制解释的免疫风险时间线**"，并与 [3.1 报告解读](./3.1_health_report_interpretation.md)、[3.2 免疫韧性画像](./3.2_immune_resilience_profiling.md) 联动闭环。

## 二、ICKG 适配性

| 需求 | ICKG 提供 | 用途 |
|---|---|---|
| 慢病-免疫关联 | `disease`(119K) + `associated_with`/`results_in` | 把慢病链到免疫风险机制 |
| 炎症/免疫指标 | `phenotype/protein/cell_type` | 追踪指标→机制 |
| 风险因果链 | 17 万+ 有向因果边 | 解释"为什么这个走势值得关注" |
| 文献来源 | 每边 `pmids` | 预警可追溯 |

## 三、技术路线

```mermaid
flowchart LR
    A[慢病/亚健康人群<br/>纵向免疫指标 + 基础病] --> B[风险特征构建<br/>趋势 + ICKG 机制先验]
    B --> C[风险评分 + 红黄绿灯分层]
    C --> D[ICKG 解释 + 证据分级<br/>复用 3.1 框架]
    D --> E[个人风险时间线 + 预警<br/>+ 复查/就医建议 + PMID]
    E --> F[强免责 / 红灯前置]
```

## 五、文献依据

- [Gao-2025] [**Large language model powered knowledge graph construction for mental health exploration**](https://doi.org/10.1038/s41467-025-62781-z). *Nat Commun*. KG+特征做风险预测的范式，可迁移到个人免疫风险追踪。
- ⭐ [Ahuja-2023] [**Immune resilience despite inflammatory stress promotes longevity**](https://doi.org/10.1038/s41467-023-38238-6). *Nat Commun*. 炎症压力下免疫功能漂移与健康结局。
- [Rjoob-2026] [**A multimodal vision knowledge graph of cardiovascular disease**](https://doi.org/10.1038/s44161-025-00757-4). *Nat Cardiovasc Res*. 多模态 KG 风险追踪思路，启示与可穿戴/影像融合。

## 六、可行性与挑战

| 维度 | 评估 | 说明 |
|---|---|---|
| 数据就绪度 | ★★ | ICKG 就绪；需要**长期纵向**个人数据，获取门槛较高 |
| 工程复杂度 | ★★★ | 趋势建模 + 风险分层 + ICKG 解释 |
| 算力需求 | ★ | 单机即可 |
| 主要挑战 | — | **长期数据留存与隐私合规**；**预警阈值校准**（避免过度预警）；非诊断边界 |
